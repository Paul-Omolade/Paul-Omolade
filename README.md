## Featured Projects

### Jelo AI

Jelo AI is an AI-assisted adaptive learning platform designed to provide personalised and interactive learning experiences.

Key features include:

* AI teacher conversations
* Personalised learning recommendations
* CBT practice and assessments
* Progress monitoring
* Voice and text-to-speech support
* Image and document analysis
* Smart lesson suggestions
* Parent and teacher controls

**Technology:** Laravel, PHP, Node.js, TypeScript, React, Flutter, Redis, MySQL, PostgreSQL and OpenAI.

---

### Smart Edu

Smart Edu is a school management and digital learning platform supporting more than **3,000 users**.

Key features include:

* Student and staff management
* Attendance tracking
* Examination and result processing
* School fee and payment management
* Parent communication
* Reporting and analytics
* Role-based access control
* Administrative workflow automation

**Technology:** PHP, Laravel, JavaScript, React, MySQL, Redis, APIs and cloud infrastructure.
